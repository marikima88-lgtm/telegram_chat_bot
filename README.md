# Ecash Telegram Bot

Это рабочий MVP Telegram-бота для сети обменных пунктов Ecash на Python с использованием aiogram 3.

## Что уже реализовано

- команда /start;
- выбор города и филиала;
- главное меню;
- базовый просмотр курсов валют;
- бронирование валюты;
- запрос индивидуального курса;
- передача заявок в чат сотрудников;
- адреса и график филиалов;
- стандартные ответы по ключевым словам;
- SQLite и простые уведомления по условиям курса.

> Состояние проекта: MVP с поддержкой живых курсов через Quiq, а также резервным локальным режимом, если внешний API недоступен.

## Важное замечание по Python

Проект рассчитан на Python 3.14, если используемые библиотеки поддержат эту версию. Если при установке появятся проблемы совместимости, лучше использовать Python 3.13.

## Как запустить

### Настройка живых курсов

Для получения актуальных курсов из Quiq добавьте токен в файл .env:

```env
BOT_TOKEN=your_bot_token_here
ADMIN_CHAT_ID=123456789
QUIQ_API_TOKEN=your_quiq_token_here
```

Если токен не задан, бот покажет локальные демонстрационные курсы из data/currencies.json.

1. Создайте виртуальное окружение.
2. Установите зависимости из requirements.txt.
3. Создайте файл .env по примеру из .env.example.
4. Запустите bot.py.

### Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 bot.py
```

## Запуск в Docker

Образ собирается в два этапа на Alpine: компиляторы остаются в промежуточном слое,
в финальный образ попадает только готовое виртуальное окружение. Вес — 109 МБ
(против 247 МБ на python:3.13-slim).

```bash
docker compose up -d --build
docker compose logs -f
```

Нужен только файл `.env` рядом с `docker-compose.yml` — в образ он не копируется,
переменные пробрасываются на старте.

Что заложено:

- контейнер работает не от root, а от пользователя `bot` (uid 1000);
- база SQLite лежит на томе `bot-data` по пути `/data/database.db`, поэтому
  переживает пересборку образа;
- `restart: unless-stopped` поднимает бота после падения и перезагрузки сервера;
- логи ротируются, максимум 3 файла по 10 МБ.

Обновление после изменений в коде:

```bash
git pull && docker compose up -d --build
```

Важно: одновременно должен работать только один экземпляр бота с данным токеном.
Если поднять второй, Telegram начнёт разрывать соединения обоих с ошибкой
`Conflict: terminated by other getUpdates request`. Для разработки заводите
отдельного бота через @BotFather.

## Следующий шаг

После запуска можно добавить реальные курсы, уведомления и административную панель.

## Инструкция для macOS

### 1. Создать папку проекта

```bash
mkdir ~/ecash-bot
cd ~/ecash-bot
```

### 2. Открыть папку в VS Code

```bash
code .
```

### 3. Открыть терминал в VS Code

Нажмите Ctrl + ` или выберите меню Terminal → New Terminal.

### 4. Создать виртуальное окружение

```bash
python3 -m venv .venv
```

### 5. Активировать виртуальное окружение

```bash
source .venv/bin/activate
```

### 6. Установить зависимости

```bash
pip install -r requirements.txt
```

### 7. Создать бота через BotFather

1. Откройте Telegram.
2. Найдите @BotFather.
3. Отправьте команду /newbot.
4. Следуйте инструкциям и получите токен.

### 8. Куда вставить BOT_TOKEN

Создайте файл .env и вставьте:

```env
BOT_TOKEN=ваш_токен_бота
ADMIN_CHAT_ID=идентификатор_чата
QUIQ_API_TOKEN=ваш_токен_quiq
```

### 9. Создать чат сотрудников

Создайте отдельный чат в Telegram для сотрудников или используйте один общий чат.

### 10. Добавить бота в чат сотрудников

Добавьте бота в этот чат и дайте ему права на отправку сообщений.

### 11. Узнать ADMIN_CHAT_ID

1. Добавьте бота в нужный чат.
2. Отправьте любое сообщение в чат.
3. Откройте ссылку вида:

```text
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

4. Найдите chat.id.

### 12. Заполнить branches.json

Откройте файл data/branches.json и добавьте нужные города и филиалы.

### 13. Запустить бота

```bash
python3 bot.py
```

### 14. Остановить бота

Нажмите Ctrl + C в терминале.

### 15. Как исправить основные ошибки

- Если бот не запускается, проверьте, что .env заполнен правильно.
- Если токен не работает, создайте нового бота через BotFather.
- Если не приходят сообщения, проверьте ADMIN_CHAT_ID.
- Если не видны кнопки, проверьте, что бот запущен и вы написали /start.
