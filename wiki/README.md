# База знаний

Это место для важных заметок, решений, вопросов и ссылок.

## Когда сюда добавлять информацию

Сюда стоит складывать:
- требования и ожидания;
- важные решения;
- вопросы, которые обсуждали;
- полезные ссылки и материалы;
- промежуточные варианты и идеи.

## Правило

Если мы обсудили что-то важное, я сохраняю это здесь, чтобы контекст не терялся.
